# Media Conversion API

!!! warning "Not yet available"
    Media conversion (image, audio, video) is **planned but not yet exposed** on the public API. There is currently no `/media/` endpoint — only [Document](docs-conversion.md) and [Font](fonts.md) conversion are live. This page is a placeholder for the upcoming surface.

When released, media conversion will follow the same 3-step shape as [Document Conversion](docs-conversion.md): submit → poll → download.
