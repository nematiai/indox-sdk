# API Reference — Overview

All endpoints are versioned under `/api/v1/`. Auth is **Bearer token** unless noted.

| Prefix | Service |
|---|---|
| `/api/v1/user/` | [Auth](auth.md) |
| `/api/v1/pdf_handler/` | [Document Conversion](docs-conversion.md) |
| `/api/v1/fonts/` | [Font Conversion](fonts.md) |
| `/api/v1/subscription/` | [Billing](billing.md) |

OpenAPI schema: `GET /api/schema/` (drf-spectacular). Interactive UI: `/api/schema/swagger-ui/`.
