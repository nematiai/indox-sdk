# indox-go

Official Indox API v1 Go SDK. OpenAPI generator output in `generated/`; idiomatic helper in `indox/`.

```bash
make sdk-gen LANG=go
go get github.com/nematiai/indox-go/indox   # when published
```

Auth: `Authorization: Bearer ak_…` (`INDOX_API_KEY`, `INDOX_BASE_URL`).

**Publish:** module proxy only with explicit approval.
