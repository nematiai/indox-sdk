# Indox Java SDK (`org.indox:indox-sdk`)

Official Indox API v1 Java client. Generated sources under `generated/`; helper `IndoxClient` under `src/`.

```bash
make sdk-gen LANG=java
```

Auth: `Authorization: Bearer ak_…` (`INDOX_API_KEY`, `INDOX_BASE_URL`).

**Publish:** Maven Central / GitHub Packages only with explicit approval.
