# indox/indox (PHP)

Official Indox API v1 PHP SDK. Generated client under `generated/`; thin auth helper in `src/IndoxClient.php`.

```bash
composer require indox/indox   # when published
make sdk-gen LANG=php
```

Auth: `Authorization: Bearer ak_…` via `INDOX_API_KEY` / `INDOX_BASE_URL`.

**Publish:** Packagist only with explicit approval.
