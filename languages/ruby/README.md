# indox (Ruby)

Official Indox API v1 Ruby SDK. OpenAPI output in `generated/`; helper in `lib/indox_client.rb`.

```bash
gem install indox   # when published
make sdk-gen LANG=ruby
```

Auth: `Authorization: Bearer ak_…` (`INDOX_API_KEY`, `INDOX_BASE_URL`).

**Publish:** RubyGems only with explicit approval.
