# indox (Rust)

Official Indox API v1 Rust SDK. Generator output in `generated/`; helper crate root in `src/lib.rs`.

```bash
make sdk-gen LANG=rust
cargo add indox   # when published
```

Auth: `Authorization: Bearer ak_…` (`INDOX_API_KEY`, `INDOX_BASE_URL`).

**Publish:** crates.io only with explicit approval.
